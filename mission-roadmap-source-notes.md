# Mission-First Roadmap Source Notes

Source: `/home/ubuntu/upload/pasted_content.txt` supplied by the project owner on 2026-08-19.

## High-value principles retained

The source prioritises a staged product loop: simplify the learner experience first, prove that the first mission works, then add curriculum depth, AI teaching, monetisation, and later optional progression systems. It recommends a learner architecture of path, unit, mission, challenge, and mastery, while keeping the visible learner interface focused on the next useful action.

The mission template most relevant to this project is: a single prompt or hook, a short demonstration or explanation, one learner move, concise feedback, optional coach help, a second practice opportunity, and a clear continuation. It further recommends one screen, one idea, one action; short primary learning copy; visual or scenario-based teaching where practical; optional depth on demand; and a visible next step.

The source proposes a staged commercial path of a free starter, a one-time unit pass, and a future academy pass. It recommends postponing recurring membership until the core loop demonstrates demand.

## Project-specific adaptations and exclusions

The academy retains the source's simplicity, try-before-buy, and optional AI-help principles. It does not adopt pressure-oriented streaks, leaderboards, token economies, public comparison, or credentials/certification claims. Any future payment product requires a claimed Stripe test sandbox before live checkout validation. Any future assessment or recognition remains educational and non-credential unless governance, standards, assessment policy, and legal review are established.

## Current implementation direction

The active learner loop is: start a voluntary five-minute mission, see one idea, try one safe action, access optional in-mission coach help, then choose the next useful step. Classroom, Student Services, and Auditorium are background support spaces rather than learner choices at entry.
